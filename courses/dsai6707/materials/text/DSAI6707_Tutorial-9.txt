Multilayer Perceptrons
 REVIEW

 An MLP contains an input layer, one or more hidden layers,
 and an output layer.

 Hidden neurons learn intermediate representations of the inputs.

 Nonlinear activation functions allow nonlinear decision boundaries.


 Without nonlinear activations, stacked affine layers reduce to
 a single affine mapping.

Forward Computation
 REVIEW

 For hidden neuron j and output neuron k:

 aⱼ = Σᵢ wⱼᵢ xᵢ + bⱼ              hⱼ = σ(aⱼ)

 zₖ = Σⱼ vₖⱼ hⱼ + cₖ               yₖ = σ(zₖ)

 wⱼᵢ and vₖⱼ are weights. The biases are bⱼ and cₖ.


 Each weight multiplies the activation entering its connection.

The Logistic Sigmoid
 REVIEW


 σ(z) = 1 / (1 + exp(−z))

 σ′(z) = σ(z)[1 − σ(z)]

Loss and Weight Updates
 REVIEW

 For one training example with target vector d:

 E = ½ Σₖ (dₖ − yₖ)²

 Gradient descent: θ(new) = θ(old) − η ∂E/∂θ

 The learning rate η controls the size of each update.


 Here δ = −∂E/∂(pre-activation), so the delta rule uses a plus sign.

Local Gradients
 REVIEW

 Output neuron k
 δₖ = (dₖ − yₖ) yₖ(1 − yₖ)

 Hidden neuron j
 δⱼ = hⱼ(1 − hⱼ) Σₖ vₖⱼ δₖ

 Parameter updates
 Δvₖⱼ = ηδₖhⱼ    Δcₖ = ηδₖ     Δwⱼᵢ = ηδⱼxᵢ    Δbⱼ = ηδⱼ

 The hidden-layer sum uses the outgoing weights from the forward pass.

Back-Propagation Procedure
 REVIEW

 1. Initialize weights and biases
 Use small random weights to break symmetry between hidden neurons.

 2. Perform the forward pass
 Compute activations and the loss for the training example.

 3. Perform the backward pass
 Compute all local gradients, then update weights and biases.

 4. Repeat over the training set
 One epoch processes the entire training set once.

Solution 3: Output Gradient
 EXERCISE 3 SOLUTION

 The chain rule gives the gradient with respect to z.

 ∂E/∂z = (y − d)y(1 − y)

 δₒ = −∂E/∂z = (d − y)y(1 − y)

 δₒ ≈ (1 − 0.462823)(0.462823)(0.537177)

 δₒ ≈ 0.133552

 Since d > y, this output local gradient is positive.

Solution 4: Hidden Gradient
 EXERCISE 4 SOLUTION

 δₕ = h(1 − h)vδₒ

 δₕ ≈ (0.622459)(0.377541)(−0.4)(0.133552)

 δₕ ≈ −0.012554

 The negative outgoing weight reverses the sign of the error signal.

 Reducing h increases the output pre-activation z = vh + c
 when v is negative.

Solution 5: Validation Error
 EXERCISE 5 SOLUTION

 Choose the checkpoint at epoch 20.
 Its validation loss, 0.120, is the lowest among the recorded values.


 After epoch 20, training loss falls while validation loss rises.

 This pattern suggests overfitting. Early stopping can retain
 the best validation checkpoint.

 Use a separate test set for the final performance estimate.

Solution 5: Small Gradients
 EXERCISE 5 SOLUTION

 Sigmoid saturation
 h(1 − h) = 0.999(0.001) = 0.000999

 This small derivative can attenuate the hidden local gradient.


 A plateau does not certify a global minimum
 Small gradients can occur in flat regions or near stationary points.
 An MLP loss surface is generally nonconvex.

 Initialization and learning rate affect convergence. An excessive
 learning rate can cause oscillation or an increase in loss.

Key Takeaways
 SUMMARY

 Nonlinear hidden units support nonlinear decision boundaries.

 Forward propagation computes activations and prediction error.

 Back-propagation applies the chain rule recursively.

 Each weight update uses its local gradient and incoming activation.

 Validation performance helps select a useful stopping point.
