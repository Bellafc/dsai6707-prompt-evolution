Crisp Sets and Fuzzy Sets
 REVIEW


                     Crisp set                                          Fuzzy set

                 χA : X → {0, 1}                                     μA : X → [0, 1]
                A sharp boundary                                   A gradual transition

                “Hot” if x ≥ 30°C                              “Hot” to a specified degree


 A fuzzy set is defined on a universe of discourse X.
 μHot(28) = 0.6 means a degree of membership of 0.6 in “Hot”.
 Membership degree is not, by itself, the probability that a temperature is hot.

Membership Functions
 REVIEW

 Triangular: (a, b, c)
  a, c: endpoints of the base
  b: location of the peak


 Trapezoidal: (a, b, c, d)
  a, d: endpoints of the base
  b, c: endpoints of the plateau

 Choose the shape and parameters to represent the intended concept.

Properties of a Fuzzy Set
 REVIEW · FINITE UNIVERSE X


                    Property                                       Definition
                Height; normality                   h(A) = maxx μA(x); A is normal if h(A) = 1
                     Support                             Supp(A) = {x ∈ X : μA(x) > 0}
                      Core                                Core(A) = {x ∈ X : μA(x) = 1}
                      α-cut                                 Aα = {x ∈ X : μA(x) ≥ α}
                Scalar cardinality                              SC(A) = Σx μA(x)


 For the ordinary α-cut: A0 = X and A1 = Core(A).

                   Operation                                   Membership function
                Complement Ac                                      μA (x) = 1 − μA(x)

                  Union A ∪ B                               μA∪B(x) = max{μA(x), μB(x)}

Convexity and Fuzzy Relations
 REVIEW

 Convexity on an ordered universe
  For a < b < c: μA(b) ≥ min{μA(a), μA(c)}.


 A fuzzy relation R on X ×Y
  μR(x, y) ∈ [0, 1] describes the strength of the relation between x and y.


 Matrix representation
  Rows correspond to X; columns correspond to Y.


 Convexity excludes a dip below both endpoints of any ordered triple.

Projection and Composition
 REVIEW

 Projection: retain one variable and take the maximum over the other.

  μdom R(x) = maxy μR(x, y)          μran R(y) = maxx μR(x, y)

 Max–min composition: combine R(X, Y) and S(Y, Z).

  μT(x, z) = maxy min{μR(x, y), μS(y, z)}


 For each output entry: take the minimum along each path, then the maximum.

Solution 2: Support and α-Cuts
 EXERCISE 2 · SOLUTION


                    Quantity                                          Result
                     Height                              h(A) = 1; therefore A is normal
                     Support                                Supp(A) = {1, 2, 3, 4, 5}
                      Core                                        Core(A) = {3}
                     0.7-cut                                      A0.7 = {2, 3, 4}

 An α-cut uses ≥ α. Support uses > 0, so A0 and Supp(A) need not coincide.

                                                                                           12
Solution 2: Cardinality
 EXERCISE 2 · SOLUTION


 Scalar cardinality sums the membership grades.

   SC(A) = 0 + 0.3 + 0.7 + 1 + 0.7 + 0.2 = 2.9

 Relative cardinality divides by the size of the universe.

   RC(A) = 2.9 / 6 ≈ 0.483

 SC(A) is a weighted count; |Supp(A)| = 5 is an ordinary count.

Solution 4: A Counterexample
 EXERCISE 4 · SOLUTION


 A is convex.
  Its membership rises, remains at 1,
  and then falls: no interior dip.

 B is not convex.
  Choose a = 1, b = 2, c = 3:
  μB(2) = 0.2 < min(0.8, 0.8).

 Normality and convexity are different properties.

Solution 5: One Entry in Detail
 EXERCISE 5 · MAX–MIN COMPOSITION

 Compute T(x1, z1) using the three possible intermediate elements.

                      Path                               Minimum along the path
                 x1 → y1 → z1                                 min(0.2, 0.7) = 0.2
                 x1 → y2 → z1                                 min(0.8, 0.6) = 0.6
                 x1 → y3 → z1                                 min(0.5, 0.8) = 0.5

  T(x1, z1) = max(0.2, 0.6, 0.5) = 0.6
 The minimum limits each path; the maximum selects the strongest path.

Key Takeaways
 SUMMARY

 Membership represents a degree of belonging.
  Keep the universe, membership function and interpretation explicit.

 Set properties use different conditions.
  Support: > 0; core: = 1; α-cut: ≥ α.

 Fuzzy operations are applied pointwise.
  Standard complement, union and intersection use 1 − μ, max and min.

 Max–min composition combines relations.
  Match the shared variable; take path minima and then their maximum.
