                   Searching Techniques

What is searching?
   • Searching is the process of looking for the solution of a
     problem through a set of states.
   • Search conditions include
      • Current state: the step of where we are
      • Goal state: the step where the solution is found
      • Actions: move one state to another
      • Cost: how many steps needed to find the solution.
   • Solution: A path from the current state to the goal state.

              Informed (Heuristic) Search
• AI problem solver employs heuristics in two situations:
    • A problem may not have an exact solution because of ambiguities in
        problem statement or available data. Example: medical diagnosis.
    • A problem may have an exact solution, but the computational cost of
        finding it may be prohibitive.
• Uninformed (blind) searches are normally very inefficient. Information
   about the problem can sometimes be used to guild the search more
   efficiently.
• Informed search explores the node that is most “likely” to be the nearest
   to a goal state.
• Informed search works successfully in many cases, but its success is not
   guaranteed.

Hill Climbing
  • Consider an eager but blind mountain climber: go uphill along the
    steepest possible path until can go no further up.
  • Hill-climbing expands the current state and evaluates its children.
       • The best child is selected for further expansion; neither its siblings
          nor its parent are retained.
  • Because it keeps no history, the algorithm cannot recover from failures of
    its strategy.
  • Hill climbing performs well if the distance estimate (quality measurement)
    is locally consistent. That is, the node with the shortest distance estimate
    will eventually lead to the goal.
  • Hill climbing may encounter the problem of stuck/trap at local optima.

                        The A* Search
• A* is an algorithm that uses heuristic to guide search while
  ensuring that it will compute a path with minimum cost.

                                                          “estimated cost”
• A* computes the function f(n) = g(n) + h(n)
                                                          “actual cost”
  • The h(n) value guides search toward heuristically promising states
    while the g(n) value prevents search from persisting indefinitely on
    a fruitless search.
  • The function h(n) relies upon some heuristic information available
    from the problem domain. It changes from heuristic to heuristic,
    and from problem to problem.
  • The design of good heuristics is a difficult, empirical problem. h(n)
    in general weights how close node n is to the goal.

                          Properties of A*
• A* generates an optimal solution if h(n) is admissible (never
  overestimates the cost to reach the destination node, i.e., the cost it
  estimates to reach the goal is not higher than the lowest possible cost
  from the current point in the path).

• A* generates an optimal solution if h(n) is consistent, i.e., for every
  node n and for every successor node n’ of n:

                                        n            h(n)
       h(n) ≤ c(n, n’) + h(n’)                                       d
                                     c(n, n’)               h(n’)
                                                   n’


    • If h(n) is consistent, f along any path is non-decreasing.
    • If h(n) is consistent, then h(n) is admissible.

                     Simulated Annealing
• What is simulated annealing? Main idea is to avoid local minima by
  accepting moves to worse solutions probabilistically
    • One of the first stochastic local search methods
    • Inspired by the analogy to physical annealing
• Physical annealing:
    • A process for obtaining the minimum energy state of a solid,
      whereby the melted solid is slowly cooled down until reaching its
      ground state
    • A specific schedule is used to cool down the solid very slowly.
• Computer simulation:
    • Metropolis algorithm is a simulation algorithm for the physical
      annealing process
• Can be applied to solve optimization problems!

                       Genetic Algorithms
• A genetic algorithm is a search-based algorithm based on natural selection,
  which can be used for solving AI optimization problems.
• Some basic terminologies:
   • Population: This is a subset of all the probable solutions that can solve
      the given problem.
   • Chromosomes: A chromosome/string is one of the solutions in the
      population.
   • Gene: This is an element in a chromosome.
   • Fitness function: This is a function that uses a specific input to
      produce an improved output. The solution is used as the input while
      the output is in the form of solution suitability.
   • Genetic operators: Genetic operators such as Selection, Crossover,
      Selection, are used for changing the genetic composition of
      chromosomes.

Selection Strategy

  •   We want to have some way to ensure that better individuals have
      a better chance of being parents than less good individuals.
  •   This will give us selection pressure which will drive the
      population forward.
  •   We have to be careful to give less good individuals at least some
      chance of being parents – since they may include some useful
      genetic material.
  •   The most commonly used selection methods include Roulette
      Wheel Selection, Rank Selection, Tournament Selection etc.

           Example: Fitness proportionate selection
Probability of xi being selected for mating is: f i f

     fi = fitness of xi   f i f = total fitness in the population


• Better (fitter) individuals have:
   • more space
   • more chances to be selected


Disadvantages:
  • Danger of premature convergence because outstanding individuals take
     over the entire population very quickly.
  • Low selection pressure when fitness values are near each other.

                         Elitism in GA
• Should fitness be constantly improved?
   • Re-introduce in the population previous best-so-far (elitism).
   • For example, keep the best 10% of parent population and re-
     introduce them in the next generation by replacing the worst 10%
     children population.
   • In GA, elitism tends to improve on the results.

                         Stopping Criterion
•   The optimum is reached!
•   Limit on CPU resources: maximum number of fitness evaluations.
•   Limit on the patience: after some generations without improvement.
•   Never draw any conclusion from a single run
     • Use statistical measures (e.g., average, standard deviation).
     • Obtain results from a number of independent runs.

Advantages of genetic algorithms
• It has excellent parallel capabilities.
• It can optimize various problems such as discrete functions, multi-
  objective problems, and continuous functions.
• It provides answers that improve over time.
• A genetic algorithm does not need derivative information.

Limitations of genetic algorithms
• They are not effective in solving simple problems.
• Lack of proper implementation may make the algorithm converge to a

The Schemata Theorem – The processing power of GA is understood in
  more rigorous terms by examining the growth rates of the various
  schemata or similarity templates contained in a population.
 A schema matches a string if at every location in the schema a “1”
  matches a “1”, a “0” matches a “0” or a “*” matches either.
 For cardinality “k”, there are (k+1)l schemata in a string; l is the
  length of the string, eg., k =2 (binary coding), l = 4 → 81 schemata.
 Order of a schema, o(S) is defined as the number of fixed positions.
  The defining length, d(S) of a schema is the distance between the
  first and the last specific fixed position.
 E.g., S1 = *1001*, S2 = 1****0, then O(S1) = 4, O(S2) = 2, d(S1) = 3,
  d(S2) = 5
