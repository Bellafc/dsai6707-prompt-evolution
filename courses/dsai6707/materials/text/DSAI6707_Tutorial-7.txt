Extension Principle
 REVIEW


 A crisp function can map a fuzzy input to a fuzzy output.

 Let f: X → Y and B = f(A), where X is finite.


  μB(y) = max { μA(x) : x ∈ X and f(x) = y }

 Each input carries its membership grade to the mapped output.
 If several inputs give the same y, retain their maximum grade.

 If no input maps to y, then μB(y) = 0.

Extension with Two Inputs
 REVIEW


 Let z = f(x, y), with fuzzy inputs A on X and B on Y.

 1. Evaluate every input pair (x, y).
   Assign the pair the grade min{μA(x), μB(y)}.


 2. Combine pairs with the same output z.

 μC(z) = max { min[μA(x), μB(y)] : f(x, y) = z }


 Throughout this tutorial, use the standard max–min extension principle.

Rule-based Expert Systems
 REVIEW


  Component                          Function

  Knowledge base                     Stores IF–THEN rules.

  Working memory                     Stores facts about the current situation.

  Inference engine                   Matches rules, selects a rule and executes it.

  Explanation facility               Shows how a conclusion follows from the rules.


 Several eligible rules form a conflict set.

 Conflict resolution may use priority, specificity or data freshness.

Linguistic Variables and Rules
 REVIEW

 A linguistic variable takes values described by fuzzy sets.

 Example: service quality on [0, 10], with terms poor, good and excellent.


 IF service is excellent OR food is delicious, THEN tip is generous.

          Antecedent connective                           Firing strength
                A AND B                                α = min{μA(x), μB(y)}
                A OR B                                 α = max{μA(x), μB(y)}

Mamdani Fuzzy Inference
 REVIEW


  Stage                          Calculation

  1. Fuzzification               Evaluate membership grades at the input values.

  2. Rule activation             Use min for AND and max for OR to obtain αk.

  3. Implication                 Clip each consequent: μCk(u) = min{αk, μBk(u)}.

  4. Aggregation                 Combine rule outputs: μout(u) = maxk μCk(u).

  5. Defuzzification             Convert the aggregated fuzzy output to a crisp value.



 Mamdani inference evaluates all applicable rules and combines their outputs.

Discrete Centroid
 REVIEW


 For a finite output universe U = {u1, …, um}:



   u* = [Σj uj μout(uj)] / [Σj μout(uj)]

 The numerator weights each output value by its membership grade.
 The denominator is the sum of all aggregated membership grades.


 The denominator must be positive. Continuous outputs require an integral.

Solution 5: Defuzzification
 EXERCISE 5 DISCRETE CENTROID


 The aggregated grades at u = 0, 10, 20, 30 are 0.6, 0.6, 0.5, 0.7.


 Numerator = 0 × 0.6 + 10 × 0.6 + 20 × 0.5 + 30 × 0.7
              = 37

 Denominator = 0.6 + 0.6 + 0.5 + 0.7 = 2.4

 u* = 37 / 2.4 ≈ 15.42%

Key Takeaways
 SUMMARY

 Extension principles propagate membership through a function.
  Use min across input grades and max over repeated outputs.


 A rule-based expert system reasons with rules and current facts.
  Conflict resolution selects an eligible rule to execute.


 Mamdani inference combines fuzzy rule conclusions.
  Clip each consequent, aggregate with max and defuzzify the result.
