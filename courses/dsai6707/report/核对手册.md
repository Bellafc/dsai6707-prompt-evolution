# 报告核对手册

**对象**：`report/report.md`（PDF：`report/report.pdf`）的每一个数字、每一条说法、每一个引用。
**目的**：让你不必相信我的文字，而是能自己找到每个说法的证据，并判断对不对。
**原则**：报告的数字全部来自 `results/`；说法来自 `code/`、`report/references.bib` 与 `results/`。找不到证据的说法，在本手册第 6 节标明。

---

## 0. 怎么用这本手册

建议按以下顺序进行，大约 60–90 分钟：

1. **先跑自动核对**（第 1 节，5 分钟）：脚本会逐项比对报告与结果文件，预期 `29/29 checks passed`。
2. **再看数字对照表**（第 2 节）：每个数字写明它在报告哪里、来自哪个文件、要怎么手动查。
3. **再看方法与代码对照**（第 3 节）：报告写的超参数、公式、流程，逐一对到代码。
4. **再看文献**（第 4 节）：34 篇论文，每篇有 arXiv 编号，可以直接打开核对作者与年份。
5. **最后看「未核对项目」**（第 5 节）：这些是我知道还没完全确认的地方。
6. **用第 7 节的清单打勾**。

手册中的路径都相对于 `courses/dsai6707/`。

文中写：第 0 代 NSGA-II、消融与 GA 都是 0.071，随机搜索 0.073；第 4 代 NSGA-II 0.121、GA 0.122、随机 0.098、消融 0.098。

### 2.4 第 5.2 节：保留事件（Table 3 与 Table 4）

**Table 3**（保留事件上 knee 与 B0 的平均值）：来源 `results/summary_table.md` 第二张表。

**Table 4**（配对检定）：来源 `results/heldout_tests.csv`。
- `mean_diff`：方法减 B0 的平均差（忠实度或分歧）。
- `ci_lo`、`ci_hi`：未经多重比较校正的 95% bootstrap 区间（`mosaic.stats.paired`，10,000 次重抽样，种子 0）。
- `p_raw`：精确 sign-flip 检定的 p 值（10 个事件共 2¹⁰ 种符号组合）。
- `p_holm`：对 8 个检定做 Holm 校正后的 p 值。

**去掉重复事件的敏感度**（文中 0.059、0.051、0.109）：来源 `results/heldout_sensitivity.csv`，`excluded_events` 栏写明被去掉的事件是 `syn-k0007`。

**为什么有一个事件要去掉**：`syn-k0007`（保留集）与 `syn-k0002`（搜索集）的文字完全相同，但 macro context 不同。**手动核对的方法**：在 Python 中执行

```python
from evo_prompt.runner import events
s = events(5, 23); h = events(10, 29)
print([(a.id, b.id) for a in s for b in h if a.text == b.text])   # 应输出 [('syn-k0002', 'syn-k0007')]
```

（在 `courses/dsai6707/code/` 目录下执行。）

### 4.3 文献核对的方法

1. 打开表中的 arXiv 链接（`https://arxiv.org/abs/<编号>`）。
2. 对照标题、作者顺序、首次提交日期（页面右侧的 `Submitted on`）。
3. 对照报告第 2 节中关于该论文的描述，检查数字与结论是否在摘要中出现。例如：MOPrompt 的「31% 更短」、ParetoPrompt 的「在不同训练与测试指标下仍稳健」。
4. 如果摘要中找不到报告描述的数字，就要改写该句，或删掉。
