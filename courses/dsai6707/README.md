## 3. 本專題的選題（詳細設計見 `PLAN.md`）

**多學派 LLM agent 的多目標 prompt 演化（NSGA-II + LLM 引導突變）**：同時演化三個互相競爭的經濟學派 agent
（Keynesian、Austrian、Monetarist）的 prompt，三個目標是學派忠實度↑、學派間分歧度↑、prompt 長度↓。
程式基礎沿用 Macro-MOSAIC（論文 repo），只用合成事件，不碰論文的 dev／test 資料。
