# Citation verification logs

Working records of the research sub-agents that checked the bibliography of the thesis drafts.

- `COMMON_BRIEF.md`: the instructions every sub-agent followed (what counts as a primary source, status values).
- `cluster_A_verification.md` to `cluster_D_verification.md` (2026-10-31): one log per topic cluster, one row per
  item, with the primary page that was read and what was checked on it.
- Logs for clusters added on 2026-11-01 for the three RQs, if present, follow the same format.

The cluster `.bib` files these logs mention were merged by topic into `../references/*.bib`. The per-key summary,
including clusters E (checked by the main session) and F (carried over from the Confirmation bibliography), is
`../CITATION_VERIFICATION.md`. Downloaded papers were not committed (copyright); every entry carries its URL or DOI.
