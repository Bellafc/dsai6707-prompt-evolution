Checked on 2026-11-01. BibTeX file: `cluster_I.bib` (same folder). Scope (RQ3): pooled forecasts across contested frameworks versus single frameworks and other sources of ensemble diversity at equal ensemble size (personas, several different models, repeated sampling of one model); calibration and coherence; whether disagreement predicts error.

Method. Each item was searched, then its primary page was read: arXiv abstract page or arXiv API record, ICLR/ICML/NeurIPS proceedings or virtual-site pages, PMLR, the official TMLR list on jmlr.org, JMLR, ACL Anthology, a publisher page, or a library catalogue. Several publisher sites refuse automated access (ScienceDirect, Wiley, INFORMS and Princeton University Press return 403; AAAI OJS and OpenReview show a bot check; APA PsycNet is script-only). For those, the publisher's own Crossref deposit (`https://api.crossref.org/works/<DOI>`) was read instead, and the notes say so. No author, page, DOI or arXiv id in the .bib was taken from memory.

Notes column. Per the extra rule, each row gives one sentence from the abstract, quoted verbatim, including the authors' own grammar (marked "Abstract:"). For three items a second sentence from the same abstract is quoted because it bears directly on RQ3 (marked "Also in the abstract:"). The book (item 14) has no abstract, so it has no quoted sentence.
