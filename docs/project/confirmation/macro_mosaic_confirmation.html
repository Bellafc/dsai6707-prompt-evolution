Literature Review I
Foundations of AI Agents in Finance
What is an AI Agent?
Wooldridge and Jennings [1] define an agent as a computational entity that perceives its environment and acts autonomously to achieve goals. Russell and Norvig [2] extend this to rational agents that select actions maximizing expected utility. The perceive-reason-act loop is foundational to all agent architectures.
Key Reasoning Paradigms
Chain-of-Thought (Wei et al. [3]) enables step-by-step intermediate reasoning in LLMs. Tree-of-Thought (Yao et al. [4]) extends this to branching search over multiple reasoning paths. Toolformer (Schick et al. [5]) trains LLMs to call external APIs within their reasoning sequences. Wang et al. [6] provide a comprehensive survey of LLM-based autonomous agents.
From Quantitative Models to Agents
Classical quantitative finance (Dixon et al. [7]) relied on statistical models, fixed rules, and supervised classifiers. LLM-based agents replace the fixed strategy with flexible natural language reasoning, enabling adaptive multi-step planning over heterogeneous inputs including price data, news, and regulatory text.
Finance-specific demands distinguish financial agents from general-purpose systems: real-time data feeds, regulatory explainability requirements, multi-asset scope across correlated instruments, and near-zero tolerance for high-stakes errors. These constraints motivate the architectural choices throughout this research.

Literature Review II
Data Sources and Modalities
Numerical Market Data
OHLCV prices, order-book snapshots, futures curves, options surfaces, macroeconomic indicators (FRED). FinRL [8] standardized market environments across exchanges. Macro state vectors require careful normalization across high-dimensional indicator spaces (35 dimensions in this work).
Textual Financial Data
Earnings call transcripts, SEC filings (10-K, 8-K), central bank statements, analyst reports, financial news feeds. Lopez-Lira and Tang [9] show that zero-shot GPT-4 headline analysis generates profitable signals. Kim et al. [10] find GPT-4 financial statement analysis rivals professional analysts on earnings prediction tasks.
Alternative and Visual Data
Satellite imagery, credit card transaction flows, patent filings, social media sentiment, chart pattern images. Each source requires custom preprocessing pipelines. Integration challenges include temporal misalignment across frequencies, quality variance across sources, and LLM context-window saturation requiring RAG or summarization [6].
RAG and Multi-Modal Fusion
Retrieval-augmented generation (RAG) selects the most relevant documents before LLM inference, circumventing context window limits. FinAgent [11] fuses numerical tool outputs with LLM reasoning via tool APIs. Agents operating on multiple modalities must align disparate representations into a coherent prompt or embedding space — a challenge directly addressed by Stage 1 of Macro-MOSAIC through dual-channel semantic and structural retrieval.

Literature Review III
Agent Design Patterns (1/2): Single-Agent and Memory-Augmented
Type 1 — Single-Agent Architectures
DRL-based agents formulate trading as a Markov Decision Process. The FinRL library [8] standardized this paradigm with PPO, A2C, and DDPG algorithms across multiple market environments. Key limitation: numerical state representations cannot easily incorporate unstructured text such as news or reports without extensive feature engineering.
LLM-based single agents replace fixed strategies with flexible language reasoning via a perceive-reason-act loop. FinGPT [12] provides open-source financial LLMs for sentiment and signal generation. Lopez-Lira and Tang [9] validated zero-shot headline-based trading profitability, confirming the viability of pure language reasoning for financial decisions.
Type 2 — Memory-Augmented Agents
FinMem [13] introduced a three-tier memory architecture inspired by human cognitive structures: working memory for immediate context, episodic memory for recent events, and semantic memory for long-term knowledge. Recency, relevancy, and importance scores govern retrieval. Raw inputs are summarized into memories; new observations trigger relevant memory retrieval.
FinAgent [11] extended this with a dual-level mechanism storing both raw observations and extracted lessons, creating a self-improving feedback loop. Diversified retrieval assigns specific retrieval types to historical information, enabling access from multiple analytical perspectives.
Memory-augmented design is critical because market regimes shift over time; the ability to recall and reason about analogous historical situations significantly improves decision quality. This principle directly motivates Stage 1 of Macro-MOSAIC.

Literature Review IV
Agent Design Patterns (2/2): Tool-Augmented, Reasoning, Multi-Agent
Type 3: Tool-Augmented
Agents access external tools: market APIs, technical indicator calculators, backtesting engines, code execution environments. FinAgent [11] integrates established trading strategies via tool APIs. QuantAgent [14] uses an inner-outer loop: the LLM generates alpha factor hypotheses (inner); backtesting tools validate them against historical data (outer). Precise numerical computation is delegated to tools, bypassing LLM arithmetic limitations.
Type 4: Reasoning-and-Reflection
Agents evaluate and iteratively improve their own reasoning. FinAgent [11] implements dual-level reflection: decision-level (was the trade outcome consistent with the reasoning?) and meta-level (are there systematic biases in the strategy?). FinMem [13] synthesizes reflections from recent memories before each decision cycle. Critical for non-stationary markets where strategies that worked in one regime fail in another.
Type 5: Multi-Agent Frameworks
Three sub-types: (a) Role-specialized teams: TradingAgents [15] assigns fundamental, sentiment, technical, and news analyst roles plus a risk management team. HedgeAgents [16] uses a fund manager orchestrating asset-class specialists. (b) Debate-driven: Bull and Bear researchers in TradingAgents [15] engage in structured debate before a trader synthesizes. Xing [17] applies heterogeneous debate to sentiment analysis. (c) Information-distillation networks: FINCON [18] compresses information between agents to prevent the "telephone effect" — detail loss across multiple agent hops.
Type 5 (continued): Hybrid Designs
Modern systems combine multiple patterns. FLAG-Trader [19] integrates LLM multi-agent reasoning with RL-based execution. Alpha-R1 [20] applies reinforcement learning within a multi-agent framework for alpha generation. Trading-R1 [21] and Fin-o1 [22] extend chain-of-thought reasoning to intraday decisions. The trend is toward architectures that combine the interpretability of language reasoning with the optimization power of reinforcement learning — the multi-school parallel reasoning in Macro-MOSAIC (Stage 2) sits at this intersection.

Literature Review V
Application Domains (1/2): Trading and Portfolio Management
Trading: Equity, Crypto, High-Frequency
Equity trading: TradingAgents [15] demonstrated multi-agent collaboration on daily stock signals, with role-specialized analyst teams feeding a trader agent. Trading-R1 [21] and FinCoT [23] explore structured chain-of-thought reasoning for stock selection. LLM agents now approach professional benchmark performance on held-out equity evaluation periods.
Cryptocurrency: FinAgent [11] and FinRL [8] both include crypto datasets. The unique dynamics — on-chain data, social media sentiment cycles, and regulatory uncertainty — make crypto a challenging testbed for agent adaptability across rapidly shifting regimes.
High-frequency trading remains primarily the domain of DRL and traditional quantitative systems due to LLM inference latency. LLM agents increasingly handle longer-horizon components such as alpha factor generation [14] and regime detection, while faster numerical models handle execution. This latency constraint motivates Macro-MOSAIC's focus on macro event-level (rather than tick-level) analysis.
Portfolio Management
DRL approaches treat portfolio weight vectors as the action space, optimizing return-risk tradeoffs across multiple assets. FinRL [8] supports multi-asset allocation with configurable algorithms including PPO and DDPG.
LLM-based portfolio management is emerging. FINCON [18] compares against Markowitz mean-variance and equal-weighted baselines on portfolio allocation tasks, demonstrating that multi-agent verbal reinforcement improves risk-adjusted returns. HedgeAgents [16] addresses multi-asset hedging through a hierarchical design where sector specialists report to a central fund manager — mirroring the organizational structure of real-world investment firms.
FinRobot [24] and FinVerse [25] extend to multi-strategy and scenario-based portfolio construction. ContestTrade [26] introduces competition-based agent selection. These works share the gap of operating without explicit macro transmission mechanism reasoning — the gap that Macro-MOSAIC addresses.

Literature Review VI
Application Domains (2/2): Risk, Advisory, Compliance, and Benchmarks
Risk Management and Fraud Detection
Traditional fraud detection relies on rule-based filters and supervised classifiers. Agent-based approaches add autonomous monitoring, adaptive learning, and multi-step reasoning [27]. LLM fraud detection agents process unstructured customer communications alongside structured transaction data, providing a holistic view of potential fraud patterns [28]. Credit risk agents (Kim et al. [10]) actively gather additional information under uncertainty and produce transparent reasoning chains for regulatory compliance. Market risk monitoring via multi-agent systems (TradingAgents [15]) assigns distinct agents to market, credit, liquidity, and operational risk dimensions, coordinating their assessments into a unified portfolio risk view.
Financial Advisory and Regulatory Compliance
Financial analysis: MarketSenseAI [29] integrates multiple information sources for S&P 100 stock analysis via LLM agents. Alpha-GPT [30] and AlphaAgent [31] target institutional-grade investment research automation. Regulatory compliance: Arner et al. [32] document the breadth of AML, data privacy, and reporting obligations. LLM compliance agents interpret regulatory text, map requirements to internal controls, and flag gaps — adapting to regulatory changes without rule reprogramming. Automated reporting: Nie et al. [33] assign collection, validation, analysis, and drafting roles across a multi-agent pipeline. AML: Agent-based systems trace layering patterns across accounts and generate suspicious activity reports with evidence chains that satisfy regulatory documentation requirements.
Benchmarks and Evaluation
Trading Metrics: Cumulative Return, Sharpe Ratio, Maximum Drawdown, Sortino Ratio, Calmar Ratio. Backtesting limitations: look-ahead bias, survivorship bias, market impact underestimation [34].
NLP Benchmarks: FinBen [35] covers sentiment, NER, QA, numerical reasoning. FinanceBench [36] tests QA over SEC filings. InvestorBench [37] evaluates investment-oriented agent end-to-end tasks. FinAgentBench [38] evaluates multi-step task completion.
Causal Reasoning: EconCausal [39] tests causal reasoning over economic events. EconLogicQA [40] tests supply-demand and macro logic chains. KalshiBench [41] evaluates prediction market calibration. These three benchmarks are planned for Macro-MOSAIC evaluation.

Research Gap I
Two Camps in the Existing Literature
Camp A: Asset-Level Signal Agents
TradingAgents [15], FINCON [18], and FinGPT [12] build multi-agent systems generating equity-level trading signals from news sentiment, technical indicators, and fundamental data. These systems excel at processing heterogeneous inputs and producing interpretable per-asset decisions through role-specialized agent architectures.
Core limitation: operation at the individual asset level. They do not trace how a Federal Reserve rate decision propagates through the credit channel to affect corporate bond spreads, equity risk premia, and currency positioning simultaneously. Macro transmission mechanism reasoning — tracing the step-by-step causal pathway from policy event to multi-asset outcome — is absent from these systems.
Camp B: Macro Simulation Agents
EconAgent [42] and Lopez-Lira and Tang [9] apply LLMs to macroeconomic simulation or event-level forecasting. These systems capture macro-level dynamics with greater theoretical grounding, simulating how economic actors respond to policy shocks and aggregate market conditions.
Core limitation: not connected to calibrated cross-asset allocation signals. MarketSenseAI [29], while integrating macro context for S&P 100 equity analysis, similarly operates without explicit multi-school parallel reasoning or formal calibration of probability outputs against resolved prediction market outcomes. The macro analysis does not terminate in actionable allocation weights.
Neither camp addresses the full path from macro event interpretation — through auditable school-structured reasoning — to calibrated multi-asset allocation signals.

Research Gap II
Three Specific Gaps Motivating Macro-MOSAIC
G1
No Multi-School Parallel Reasoning System
No existing system generates explicit, auditable causal chains where structurally distinct economic frameworks (Keynesian, Austrian, Monetarist) independently analyze the same macro event and produce divergent outputs that are then formally aggregated. FOMC In Silico [43] comes closest by assigning dovish and hawkish personas to FOMC member agents, but these represent individual viewpoints on a single policy variable (the federal funds rate) rather than structurally distinct theoretical frameworks applied to general macro events across full asset universes.
G2
No Macro-Episode Analogy Retrieval at the Structural Level
Historical analogy retrieval combining semantic similarity over event narratives with structural similarity over macro state vectors has not been addressed in surveyed systems. Existing financial RAG systems [11, 44] retrieve similar price patterns or sentiment-level few-shot examples, not structured narratives of comparable macro crises with documented transmission mechanisms and multi-asset outcomes spanning the full 19-channel taxonomy.
G3
No Verified End-to-End Macro-to-Allocation Pipeline
The literature lacks a verified end-to-end pipeline connecting qualitative macro event interpretation through calibrated probability distributions to cross-asset allocation signals, evaluated against both reasoning benchmarks (EconCausal [39], EconLogicQA [40]) and realized financial outcomes via walk-forward backtesting.

Problem Formulation
Given macro event e (e.g., a central bank decision or geopolitical shock) and prevailing macro state s (interest rates, inflation, credit conditions), the system produces three outputs:
1. {C_k(e,s)} — K school-specific causal chains
2. {(S_j, p_j)} — calibrated scenario probabilities
3. {f_i} — fractional Kelly allocation weights per asset
The three outputs are produced sequentially by Stages 2, 3, and 4 respectively, with Stage 1 supplying retrieved historical analogies as context for Stage 2.
Why These Three Economic Schools?
Each school provides structurally distinct causal pathways for the same macro event, enabling genuine ensemble diversity rather than stylistic variation.
Keynesian (JEL E12): demand management, fiscal multipliers, aggregate demand transmission, IS-LM framework, liquidity trap analysis
Austrian (JEL B53): capital structure distortion, malinvestment, Austrian Business Cycle Theory (ABCT), heterogeneous capital, time preference
Monetarist (JEL E41/E51): quantity theory (MV=PQ), money supply dynamics, long and variable lags, natural rate hypothesis
FOMC In Silico [43] demonstrates the value of multi-perspective policy simulation; Macro-MOSAIC generalizes this to full multi-asset allocation across a structurally diverse school set.

Macro-MOSAIC II
Stage 1: Historical Analogy Retrieval
Dual-Channel Retrieval Design
For query event e with macro state s, each stored episode e_i receives a composite score combining semantic and structural similarity:
score(e,eᵢ) = α·cos_sim(vₑ,vₑᵢ) + (1−α)·exp(−dM(s,sᵢ))
Semantic channel: Sentence transformer embeddings (e.g., BGE-large-en or all-MiniLM-L6-v2) over episode narrative text fields, indexed via FAISS with inner-product search. Captures thematic similarity — a banking crisis query retrieves other banking crises regardless of the macro regime.
Structural channel: Mahalanobis distance over normalized 35-dimensional FRED macro context vectors, using the pooled covariance matrix across all 141 episodes.
dM(s,sᵢ) = sqrt((s−sᵢ)ᵀ Σ⁻¹ (s−sᵢ))
Captures macro-regime similarity — episodes in tight monetary conditions retrieve other tight-money environments regardless of narrative framing. The weighting parameter α is tuned on a held-out validation set of 20 episodes.

School-Specific Vocabulary Design
Each school is defined by must-have keywords, strong-signal keywords, and anti-signal keywords sourced from school canonical texts and JEL classifications. The consistency score weights these three components; the anti-signal term penalizes cross-school leakage.
Keynesian (JEL E12): aggregate demand, fiscal multiplier, output gap, IS-LM, liquidity trap, automatic stabilizers. Anti-signals: malinvestment, ABCT, quantity theory, MV=PQ.
Austrian (JEL B53): malinvestment, ABCT, capital structure distortion, heterogeneous capital, time preference, Mises, Hayek. Anti-signals: multiplier effect, aggregate demand, quantity theory.
Monetarist (JEL E41/E51): MV=PQ, quantity theory, M2, long and variable lags, natural rate, Friedman rule. Anti-signals: multiplier effect, endogenous money, malinvestment.
Synthetic trajectory generation: GPT-4o used as an oracle teacher with school-specific prompts. 1,500 total trajectories across three schools, domain-balanced across event categories. Training episodes: 117 complete episodes; 24 held out for diversity testing.

Macro-MOSAIC IV
Stage 3: Bayesian Aggregation and Calibration (Planned)
Regime-Conditional Bayesian Weighting
School weights θ_k(r) are conditioned on the current macro regime r (expansion, contraction, stagflation, deflation). In each regime, the school that historically produced better-calibrated probability forecasts receives higher weight, updated via Brier Score performance on resolved prediction market questions.
P(S_j | e,s) = Σ_k θ_k(r) · P_k(S_j | e,s,C_k)
Each school's scenario probability P_k(S_j | e, s, C_k) is extracted by parsing the [Output] block from Stage 2. The structured output requirement (93–99% block presence after SFT) ensures reliable extraction for downstream aggregation. Ledoit-Wolf shrinkage [48] is applied when estimating covariance matrices to handle the small-sample regime.
Calibration data: resolved macroeconomic and geopolitical prediction questions from Polymarket (public API and Kaggle dumps) and Metaculus (Python SDK), filtered for monetary policy, inflation, GDP, elections, and conflict topics.
Platt Scaling Calibration
Raw LLM probability outputs are systematically overconfident. Platt scaling [47] fits a two-parameter sigmoid (a, b) to transform raw scores into calibrated probabilities, trained on the resolved prediction market outcomes:
p_calibrated = σ(a · p_raw + b)
Calibration quality is evaluated via Expected Calibration Error (ECE) and reliability diagrams comparing predicted probabilities to empirical outcome frequencies across probability bins. A well-calibrated model's reliability curve lies close to the diagonal.
Status: Stage 3 is planned. Requires Stage 1 retrieval engine completion to supply analogy-augmented context to school agents. Timeline: Weeks 2–4 of the future schedule.

Macro-MOSAIC V
Stage 4: Asset Allocation Signal Generation (Planned)
Fractional Kelly Criterion
Given calibrated scenario probabilities from Stage 3, the expected log-return for each asset is computed and the fractional Kelly formula applied with f = 0.25 (quarter-Kelly) to limit variance inflation relative to full Kelly:
f* = (p·b − q) / b
f_i = 0.25 · f*_i (fractional multiplier)
where p is the probability of the favorable scenario, b is the payoff odds ratio (expected gain divided by expected loss), and q = 1−p. The fractional multiplier 0.25 is consistent with institutional practice (López de Prado [49]) for controlling variance inflation from Kelly sizing. The result f_i is the position size for instrument i expressed as a fraction of capital.
For assets with multiple scenarios (long, neutral, short), the position is the probability-weighted combination across scenarios, capped by the fractional Kelly bound per instrument.

Eight instruments spanning major liquid asset classes, selected for accessibility via CME and ETF markets:

Episode Database: Construction and Validation
Database Construction
The episode database covers 141 macro events from 1971 to 2025, spanning oil shocks, sovereign debt crises, monetary policy pivots, financial crises, pandemics, and geopolitical disruptions. Each episode is represented by:
(1) Event narrative (text description and date range)
(2) 35-dimensional FRED macro context vector at event onset
(3) Category tags across 10 event types
(4) Difficulty label: medium, hard, or very hard
(5) Multi-asset reaction data across 22 instruments
(6) Documented transmission channels (19 types)
(7) School-specific causal interpretations for 117 of 141 episodes
Temporal distribution spans 1971–2025: oil shocks and stagflation (1970s), disinflationary recessions (1980s), EM contagion and financial crises (1990s), Global Financial Crisis (2008–2009), European debt crisis (2010s), COVID-19 and post-pandemic inflation (2020–2023), and recent events including SVB failure, Trump tariffs, and Fed pivot (2023–2025).

Preliminary Results II
Training Data and Evaluation Protocol
Synthetic Trajectory Generation
For each of the three schools, 500 synthetic agent trajectories are generated using GPT-4o as an oracle teacher, prompted with school-specific stylistic and conceptual constraints from JEL classification sources. Each trajectory must follow the required structure:
[Think] → [ToolCall] → [Observe] → [Output]
The [Output] block must contain: (1) a causal chain tracing the event through specific transmission mechanisms to asset class impacts, (2) three to five discrete scenario probability distributions summing to 1.0, and (3) directional signals (long, short, or neutral) for each of the eight tracked instruments. Total synthetic dataset: 1,500 trajectories across three schools, domain-balanced across event categories (monetary policy 15%, geopolitical 12%, inflation data 10%, others proportional).
Training source: 117 complete episodes. Held-out set: 24 episodes used for trajectory diversity testing. Note that Stage 2 adapter training was completed prior to Stage 1 retrieval engine construction because the two components are independent: LoRA adapters require only episode narratives, not the embedding index infrastructure.

Interpreting the Keynesian Result
The apparent −8.1% regression is a scoring artifact, not a quality degradation. Decomposing the score reveals: must-have keyword coverage improves (3.0 → 3.4 out of 7), anti-signal contamination drops to zero (0.44 → 0.00), and [Output] block presence rises from 59% to 97%. The strong-signal decline (2.1 → 0.9) reflects appropriate specialization toward New Keynesian axiomatic structure — the adapter avoids Post-Keynesian terms outside its sub-school scope (e.g., "endogenous money," "Minsky moment"). For the downstream Bayesian aggregation stage, output parsability and school purity dominate keyword density as quality indicators.
Monetarist and Austrian Gains
The Monetarist adapter achieves +129.7%, producing MV=PQ, "quantity theory," and "long and variable lags" as natural reasoning components (must-have hits: 2.6 → 3.6 out of 6; strong-signal: 1.4 → 2.4). The base Austrian agent shows the highest contamination at 1.21, often producing mainstream Keynesian language ("output gap," "aggregate demand"); SFT reduces contamination by 51.2%.
Pipeline implication: contaminated school outputs that partially overlap with other schools' perspectives supply redundant rather than complementary signals to Stage 3 Bayesian aggregation, reducing the effective diversity of the ensemble and undermining the multi-school design rationale.

Interpretation
SFT gains are largest for data-driven event categories: inflation data (+0.261), economic data (+0.259), and employment data (+0.227). These categories offer the greatest theoretical differentiation across schools because each framework predicts distinct causal mechanisms for the same data release.
Example: unexpected CPI reacceleration
Monetarist adapter: attributes the outcome to prior M2 growth with a 12–18 month lag, per the quantity theory of money and the "long and variable lags" doctrine.
Austrian adapter: frames the outcome as a consequence of malinvestment-driven supply bottlenecks from the prior credit expansion phase, with capital structure misalignment amplifying price pressures through heterogeneous capital goods.
Gains are near-zero for geopolitical events (−0.002), where all three schools tend to converge on similar supply-shock analyses with limited theoretical differentiation. The dominant causal mechanism (sudden supply disruption) is unambiguous across economic frameworks, leaving little room for school-specific scaffolding to add value.
This pattern is consistent with the ensemble learning rationale for multi-school design: the system generates the greatest value over single-school approaches precisely when theoretical frameworks diverge, which occurs most strongly on data-driven events where monetary, fiscal, and structural interpretations compete.

Preliminary Results VII
Scope of Current Evidence: What These Results Do and Do Not Establish
What Is Established (Stages 1 and 2)
(1) School-style vocabulary consistency is substantially improved for Austrian (+118.8%) and Monetarist (+129.7%) adapters. The Keynesian adapter shows qualitative improvement in school purity despite a composite score decline driven by appropriate New Keynesian sub-school specialization.

(2) Cross-school contamination is near-eliminated: Keynesian anti-signal hits drop from 0.44 to 0.00; Monetarist from 0.88 to 0.02. This is a necessary precondition for genuine ensemble diversity in Stage 3.

(3) Structured output parsability improves dramatically: [Output] block presence rises from 51–81% (base) to 93–99% (SFT), enabling reliable downstream parsing by the Bayesian aggregation stage.

(4) Inter-school diversity in directional asset signals increases (Jaccard 0.778 → 0.853, p < 0.01), indicating that fine-tuned schools generate meaningfully different analytical perspectives rather than stylistic variations of the same mainstream analysis.
What Is Not Yet Established (Requires Stages 3 and 4)
(1) Whether fine-tuned adapters produce better causal reasoning in terms of economic accuracy or logical coherence. Current evaluation is keyword-based on held-out synthetic events, not human-judged economic validity. EconCausal [39] and EconLogicQA [40] evaluation is planned.

(2) Whether school-specific probability outputs are better calibrated than the base model on resolved real-world prediction markets. Calibration evaluation requires Stage 3 and Polymarket/Metaculus data.

(3) Whether the end-to-end pipeline generates superior trading performance relative to buy-and-hold, BVAR, or GPT-4o zero-shot baselines. This requires Stage 4 walk-forward backtesting on 2023–2025 data.

The current results should be interpreted as input-quality validation for Stage 3, not as evidence of end-to-end system performance.
Summary: These preliminary results demonstrate that LoRA fine-tuning on 500 synthetic trajectories per school produces meaningfully differentiated economic reasoning agents. The four measured properties (consistency, contamination, parsability, diversity) are necessary preconditions for the downstream Bayesian aggregation stage, not sufficient evidence of end-to-end value.

External Baselines
All ablations and baselines are evaluated on the same 2023–2025 out-of-sample walk-forward backtest period.
Buy-and-hold: equal-weight static allocation across the eight instruments, rebalanced quarterly.
Random walk: random directional allocation with fractional Kelly sizing, providing a noise floor benchmark.
BVAR: Bayesian Vector Autoregression over the eight instruments and 35 FRED macro indicators — a strong classical macro forecasting baseline.
GPT-4o zero-shot: direct multi-asset allocation from GPT-4o with the same event and macro context, no fine-tuning, no school structure.
Statistical Testing
All pairwise comparisons between Macro-MOSAIC and each baseline or ablation variant use the Ledoit-Wolf Sharpe ratio test [48] with a 95% bootstrap confidence interval (1,000 bootstrap resamples of the out-of-sample period). Multiple comparison correction applied via Bonferroni adjustment across the five ablation variants and four external baselines.
Primary metric: annualized Sharpe Ratio on the 2023–2025 out-of-sample period. Secondary metrics: Maximum Drawdown, Calmar Ratio, and directional accuracy of the per-asset allocation signal compared to realized returns at the 1-month horizon.

Future Plan III
Risk, Governance, and Auditability
Model Risk
LoRA adapters are trained on synthetic GPT-4o-generated trajectories, which may inherit GPT-4o biases or errors in school attribution. Mitigations: (1) trajectory quality filtering via consistency score thresholding before inclusion in the fine-tuning corpus; (2) human spot-checking of 50 trajectories per school for school-attribution accuracy; (3) planned evaluation against human-expert economic reasoning on EconLogicQA [40] to assess causal reasoning quality beyond keyword proxies. The keyword-based consistency metric is a necessary but not sufficient measure of reasoning quality.
Data and Calibration Risk
Historical analogy retrieval assumes that past macro episodes provide useful structural information for current events. Regime novelty — events with no structural precedent in the 1971–2025 reference set — may degrade retrieval quality. Prediction market calibration data covers macroeconomic topics but may undersample extreme tail events with low historical frequency. Platt scaling parameters are estimated on finite calibration samples; out-of-sample calibration degradation is a known risk, monitored via rolling Expected Calibration Error plots during the backtest period.
Financial and Operational Risk
The fractional Kelly criterion (f = 0.25) substantially reduces but does not eliminate ruin risk under adverse scenarios. Walk-forward backtesting controls look-ahead bias; survivorship bias is addressed by including delisted instruments where available. No live trading is planned during the research period: all evaluation is on historical data. LLM inference latency (seconds per response) precludes use in high-frequency or real-time execution contexts — Macro-MOSAIC is designed for event-driven macro analysis at the hourly-to-daily frequency.
Auditability Design
Every Macro-MOSAIC output carries a complete audit trail: Stage 1 provides the top-k retrieved analogies with similarity scores and historical FRED values; Stage 2 provides school-specific [Think] chains and [Output] blocks with explicit causal steps and named transmission mechanisms; Stage 3 provides regime-conditional school weights and calibrated probability distributions with confidence intervals; Stage 4 provides the Kelly calculation inputs (p, b, q per scenario per instrument) and resulting allocation weights. This full trace distinguishes Macro-MOSAIC from black-box prediction systems and supports the regulatory transparency requirements relevant to institutional investment applications (Arner et al. [32]).
